Tracki — Finanzas personales

Aplicación de finanzas personales construida con Next.js 16 (App Router) y React 19, con Supabase como backend de autenticación y base de datos Postgres. Centraliza cuentas bancarias, transacciones categorizadas y objetivos de ahorro, con un panel de estadísticas construido con Recharts.

  • Rutas del dashboard protegidas con Middleware de Next.js (Edge Runtime) + Row Level Security de Supabase a nivel de base de datos
  • Gestión de cuentas, transacciones y objetivos de ahorro con seguimiento de progreso
  • Estadísticas en tiempo real: evolución del balance, gasto por categoría y por mes
  • Filtrado global por cuenta mediante Context API, con animaciones de Framer Motion
Next.js 16 React 19 TypeScript Supabase Tailwind CSS Recharts Framer Motion

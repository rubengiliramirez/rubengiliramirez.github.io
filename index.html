Plataforma de gestión de finanzas personales

Aplicación web construida en Node.js con base de datos en Supabase, pensada para centralizar tus cuentas bancarias, ahorros y gastos en un solo sitio. Incluye un sistema de autenticación con middleware propio que protege las rutas privadas.

  • Registro e inicio de sesión con middleware de autenticación
  • Gestión de cuentas bancarias, ahorros y gastos
  • Base de datos relacional en Supabase
Node.js Supabase JavaScript Middleware / Auth

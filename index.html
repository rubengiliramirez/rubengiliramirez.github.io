Tracki — Finanzas personales

El problema

Controlar ingresos, gastos y objetivos de ahorro de varias cuentas en un mismo sitio, de forma sencilla y visual.

Qué construimos

Una aplicación web completa con Next.js 16, React 19 y TypeScript sobre Supabase (autenticación y PostgreSQL). Cada usuario gestiona sus cuentas, registra movimientos por categoría, sigue sus objetivos de ahorro y consulta estadísticas de su balance.

Decisiones técnicas

  • Autorización en la base de datos con Row Level Security: cada usuario solo accede a sus propias filas, aunque la consulta salga del navegador.
  • Trigger en PostgreSQL (handle_new_user) que crea el perfil del usuario al registrarse.
  • Filtro global por cuenta con Context API: el selector afecta a todo el dashboard.
  • Estadísticas con Recharts: evolución del balance, gasto por categoría y comparativa por mes.

Mi papel

Proyecto en pareja sin reparto de módulos: diseñamos, programamos y revisamos juntos cada parte, del modelo de datos a la interfaz.

Modelo de datos

PostgreSQL · 5 tablas relacionadas

  • usuarios= auth.users
  • cuentas→ relacionada con usuarios
  • categorias→ relacionada con usuarios
  • transacciones→ relacionada con cuentas · categorias · usuarios
  • objetivos→ relacionada con usuarios

Todas las tablas de datos cuelgan del usuario mediante id_usuario, y Row Level Security filtra las filas según la sesión.
